# Medisent

Telegram-бот подбора поставщиков медицинских изделий с проверкой регистрации
в реестрах Росздравнадзора и автоматической сборкой коммерческого предложения.

- **Техническое задание:** [`docs/SPEC.md`](docs/SPEC.md)
- **Рабочие договорённости и правила проекта:** [`CLAUDE.md`](CLAUDE.md)
- **Скилл сборки КП в PDF:** [`skills/kp-builder/SKILL.md`](skills/kp-builder/SKILL.md)

Реализация ведётся по этапам 0 → 8, описанным в ТЗ; каждый этап заканчивается
проверяемым результатом и критерием приёмки.
