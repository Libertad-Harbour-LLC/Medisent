# Печать, подпись, логотип: подготовка и посадка

## Почему оттиск выглядит фальшиво

Три причины, в порядке частоты:

1. **Белая подложка вместо прозрачности.** Скан сохранён как JPEG или как PNG без альфы. На белой бумаге незаметно, но стоит печати наехать на таблицу или подпись — виден прямоугольник.
2. **Печать не касается подписи.** На бумаге оттиск ставят частично поверх подписи. Аккуратно поставленный сбоку кружок читается как вставленная картинка.
3. **Плоское наложение.** Без `mix-blend-mode: multiply` оттиск лежит поверх линий, а не пропускает их сквозь себя. Именно из-за этого запасной рендер через WeasyPrint хуже: он этот режим не поддерживает.

## Как получить чистый PNG из скана

Сканируй 600 dpi, без автокоррекции, на белом листе. Дальше — любым из способов:

**ImageMagick, синяя печать:**
```bash
magick stamp_scan.jpg -fuzz 22% -transparent white \
       -channel A -blur 0x0.6 -level 40%,100% +channel stamp.png
```

**Подпись чёрной ручкой:**
```bash
magick sign_scan.jpg -colorspace Gray -level 35%,85% \
       -transparent white signature.png
```

Проверь результат: `python scripts/check_assets.py`. Если скрипт говорит «почти всё непрозрачно» — подними `-fuzz` и повтори.

Сканы печати и подписи держи вне репозитория и вне облачных папок с общим доступом. Это фактически ключи от подписи документов.

## Подгонка геометрии

Всё живёт в `assets/brand.json`, править шаблон не нужно.

```json
"stamp": {
  "size_mm": 38,        // диаметр гербовой печати обычно 38-42 мм
  "rotate_deg": -7,     // 0 выглядит машинно, ±5-12 естественно
  "offset_x_mm": 34,    // вправо от левого края блока подписи
  "offset_y_mm": 0,     // вниз от верха блока
  "opacity": 0.88       // 0.82-0.92; ниже 0.8 похоже на выцветание
}
```

Подгоняй итеративно: собери с `--html-only`, открой в браузере, посмотри, поправь цифры. На PDF не переходи, пока посадка не устроит — так быстрее.

Ориентир: оттиск перекрывает подпись примерно на треть, левый край печати заходит на хвост росчерка, низ печати не наезжает на строку с расшифровкой ФИО.

## Логотип

Прозрачный PNG высотой от 200 px, лучше 400+. SVG шаблон тоже примет, но тогда в `brand.json` укажи имя файла с расширением `.svg` — data-URI соберётся с правильным MIME.

Если логотип светлый и теряется на белом — не подкладывай плашку в шаблоне, подготовь версию логотипа для светлого фона отдельным файлом.

## Многостраничные КП

Блок подписи помечен `page-break-inside: avoid` и уезжает на последнюю страницу целиком. Если позиций много и подпись осталась одна на пустой странице — сократи вводный абзац или объедини мелкие позиции: это правильнее, чем ломать CSS.

## Юридическая сторона

Факсимильная подпись и графический оттиск в PDF — это оформление, а не юридически значимая подпись. Для договоров, которые нужно подписать по-настоящему, нужна электронная подпись: в каталоге aiskills.team под это есть DocuSeal (self-hosted, данные остаются у вас) и n8n-шаблон «Цифровая подпись PDF через API» с PFX-сертификатом. КП это обычно не требует, договор по итогам КП — требует.
